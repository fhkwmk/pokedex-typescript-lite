# Pokédex TypeScript Lite

Mini-projeto de back-end em Node.js com TypeScript, consumindo a PokéAPI e gerenciando um catálogo local de Pokémon.

## 🚀 Como Executar o Projeto

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/fhkwmk/pokedex-typescript-lite.git
   cd pokedex-typescript-lite
   ```

2. **Instalar as dependências:**
   ```bash
   npm install
   ```

3. **Executar a aplicação em modo de desenvolvimento:**
   ```bash
   npm run dev
   ```
## 🛠️ Tecnologias Utilizadas

- **Node.js** & **TypeScript**
- **tsx** (Execução direta do TypeScript)
- **PokéAPI** (API REST de Pokémon)
